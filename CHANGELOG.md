# World Color Code — Changelog

## 12.1.5.1

### New features

**Minimap colors**
- You can give treasure icons on your minimap a color. Each zone has its own list, and each treasure can have its own color. Open the window with /wcc or /worldcolor. The zone you are standing in is marked.
- Click a color to change that treasure. Right-click a color to put it back. The color beside the zone name changes every treasure in that zone, and you can still change a single one after that. Hide takes a treasure off the minimap tint. Show puts it back. Remove deletes a treasure you added.
- Add is for a name you type. Nearby lists treasures currently on your minimap, so you can add one without typing it. Show all includes rares and other icons that are not treasures.
- The list is treasures you can loot again. Undermine also has the old list. Magic-Bound Chest is teal, Shiny Trash Can is cyan, and Overflowing Dumpster is yellow. The other old Undermine names start pink. Each kind starts with its own color. On the Coiled Isle, Cracked Canopic Jar and Venom-Clotted Bauble start as different colors. A zone with nothing in it yet is still on the list, so you can add a name.
- The zone list starts with Midnight. The zone list and the treasure list each have a scrollbar.
- It defaults to on. The switch is at the bottom of the window. Shipped names are the English minimap names. A treasure you add from Nearby uses the name your client shows. A cave uses the list for the zone above it when that cave does not have its own list.
